## 1. 一句话定位

「用专注时间养出一片小海底」——一个安静的桌面专注计时器（番茄钟），每完成一轮专注，水族馆里的水草就长高一点，偶尔有鱼、虾、螃蟹来访；带访客图鉴、20 种离线背景音。（来源：README.md）

## 3. 功能现状（来源：README.md 功能节 + CHANGELOG.md）

### 3.1 专注计时
- 默认 25 分钟专注 / 5 分钟休息，可在设置调整，新时长从下一轮生效
- 开始、暂停、继续、提前结束；任务名称可选填；空格键开始/暂停
- 计时由 Go 后端负责，界面隐藏不影响计时；休眠自动暂停（挂起 >5 秒），休眠时间不计入专注
- 正常退出保存并暂停；重开后保持静音需手动继续；每 30 秒自动存档，重要操作立即存档
- 提前结束记录已投入时间但不增加成长；完成休息也不增加成长
- 完成提示音可单独开关；静音时仍有文字提示和系统通知
- 日记保留最近 1000 条，界面显示最近 30 条；总时长和成长永久保留

### 3.2 成长与访客（核心差异化）
- 每完成一轮：水草长高；每三轮多一株植物；长满后数量封顶，画面不拥挤
- 第一轮必定遇见小丑鱼；之后每完成一轮有 1/3 概率遇见访客
- 访客物种：**15 种** = 4 种鱼 + 6 种虾 + 5 种蟹（小丑鱼、清洁虾、火焰虾、油彩蜡膜虾、枪虾、皮皮虾、琵琶虾、寄居蟹、翡翠蟹、瓷蟹、箭蟹、梭子蟹等）
- 出场规则：没见过的先来；15 位都见过之后老朋友再来；图鉴永久保存（来源：README + CHANGELOG 0.3.0 + git log）
- 每种生物按真实物种绘制；鱼摆尾、悬停、转身、彼此保持距离；虾蟹在沙地石头爬行、躲石缝/洞/螺壳，同一时间只有几只在外活动
- 每次休息可以喂一次鱼：鱼食慢慢下沉，鱼吃剩的落沙地由虾蟹捡走；不照料也不会死鱼、不扣装饰
- 图鉴画像与水缸生物同一套画法

### 3.3 背景音（20 种）
- 海浪、雨声、雷雨、溪流、气泡、煮沸、深海、风声、篝火、森林、夏日、夏夜、沙漠、晨间、时钟、木鱼、咖啡馆、卡农、车流、粉红噪音
- 19 种为 CC0 公共领域实地录音（Freesound，卡农为美国空军乐团作品），随程序打包，播放不联网；粉红噪音实时合成
- 无接缝循环（等功率交叉淡化）；时钟/木鱼接缝落在敲击之间；卡农播完停顿约 2 秒；其余随机起点
- 开始/继续专注时按开关自动播放；暂停/结束/完成停止；休息默认静音；首次不自动出声；重启不自动播放
- 合计约 27 MB 录音，程序体积约 41.9 MB（来源：docs/superpowers/plans/2026-10-11-real-ambience-recordings.md）

### 3.4 桌面体验
- 桌面挂件模式（紧凑置顶小窗，400×350）+ 完整窗口（1100×800）；挂件与展开窗口留在当前显示器（来源：main.go）
- 收起到菜单栏（托盘）；菜单栏小鱼专注时轻轻游动、暂停/休息停住
- 全局快捷键 `CmdOrCtrl+Shift+A`
- 系统「减少动态效果」时海底与菜单栏保持静态，计时与背景音正常（0.3.0 起）
- 自动更新：每 4 小时检查一次（0.2.3 起），托盘/设置可手动「检查更新」；签名更新包（0.2.2 起）
- 反馈入口：计时设置 + 托盘右键菜单「问题反馈」（0.2.1 起）
- 更新签名私钥不入库（最新提交），MyGo 0.6.0 升级（最新提交）

### 3.5 技术栈（来源：README + go.mod + mygo.json + main.go）
- Go 1.27.1 + MyGo 0.6.0 桌面框架；`//go:embed web` 内嵌前端，无 JS 构建、无需 Bun、无前端依赖
- macOS 用 WKWebView；浏览器模式 `-web 127.0.0.1:4173` 仅监听回环
- 存档 `aquarium.json`：macOS 在 `~/Library/Application Support/小海底`；`-data-dir` 可指定
- 自动更新：GitHub Releases + 签名公钥（mygo.json updates 配置）
- 测试：Go 测试（计时/存档/访客/录音/动态效果）+ Node 端到端测试（tests/*.test.mjs）
- 包名/标识符：dev.mygo.examples.aquarium（注意：仍是 mygo 示例风格 identifier，见 mygo.json——「推断」：正式产品化时可能需要独立 bundle id）
