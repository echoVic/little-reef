# 小海底

用专注时间养出一片小海底。每完成一轮专注，水草就长高一点，偶尔还会有鱼、虾或螃蟹来做客。这是一个安静的桌面专注计时器，带水族馆、访客图鉴和 20 种背景音。

## 下载

需要 macOS 12 或更高版本，以及 Apple 芯片的 Mac。到 [Releases](https://github.com/echoVic/little-reef/releases) 下载最新的 `little-reef-<版本>-macos-arm64.dmg`，打开后把“小海底”拖进“应用程序”即可。

Windows 和 Linux 暂时没有安装包，可以[从源码构建](#从源码构建)。

## 功能

- 默认专注 25 分钟、休息 5 分钟，可以在设置里调整，新时长从下一轮开始生效。
- 开始、暂停、继续、提前结束，任务名称可选填。按空格键开始或暂停。
- 每完成一轮，海底就成长一点：水草逐渐长高，每三轮多一株植物；长满后数量不再增加，画面不会拥挤。
- 第一轮必定遇见小丑鱼，之后每完成一轮，有三分之一的机会遇见访客：4 种鱼、6 种虾和 5 种蟹。没见过的朋友先来，15 位都见过之后，老朋友会再来做客。图鉴会一直保存。
- 每种生物都照真实物种来画。鱼会摆尾、悬停、转身，彼此保持距离；虾蟹在沙地和石头上爬，会躲进石缝、洞里或螺壳里，同一时间只有几只在外面活动。
- 每次休息可以喂一次鱼。鱼食慢慢下沉，鱼吃剩的落到沙地上，由虾蟹捡走。不用一直照料，中断或离开也不会死鱼，也不会扣掉装饰。
- 20 种背景音单选，可单独调音量和开关，详见[背景音](#背景音)。
- 完成提示音可以单独开关。静音时，完成后仍有文字提示和系统通知。
- 支持桌面挂件模式、收起到菜单栏，以及全局快捷键 `CmdOrCtrl+Shift+A`；挂件与展开后的窗口留在当前显示器。
- 专注时，菜单栏的小鱼会轻轻游动；暂停或休息时停住不动。系统开启「减少动态效果」时，海底与菜单栏都保持静态，计时和背景音继续正常工作。
- 「这段时间」折叠面板：展开可看本周、本月和累计的专注时长与轮数、一起度过的天数、图鉴进度和当前成长阶段；只做正向记录，不显示连续打卡，也没有目标和提醒。挂件模式不显示它。

## 背景音

海浪、雨声、雷雨、溪流、气泡、煮沸、深海、风声、篝火、森林、夏日、夏夜、沙漠、晨间、时钟、木鱼、咖啡馆、卡农、车流和粉红噪音。

- 除粉红噪音是实时合成的，其余都是公共领域的录音：18 种来自 Freesound 上以 CC0 发布的录音，卡农是美国空军乐团的演奏（美国政府作品）。每条的出处见 [THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt)。录音都打包在程序里，播放时不联网。
- 声音循环播放，听不出接缝。时钟和木鱼过接缝时节奏不乱；卡农整首播完后，停顿约两秒再从头开始；其余声音每次从随机位置开始。窗口收进菜单栏后声音也不会断。
- 开始或继续专注时，按声音开关自动播放；暂停、结束或完成时停止。休息时默认静音，可以手动打开。
- 首次打开不会自动出声。声音类型、音量和开关状态都会保存，但重启后不会自动播放。
- 系统不支持网页音频、播放受限或录音无法解码时会提示，计时不受影响。

## 存档与计时规则

- 计时由 Go 后端负责，界面隐藏不影响计时。
- 电脑休眠，或者程序被系统挂起超过 5 秒，计时会自动暂停，休眠的时间不算进专注。
- 正常退出时会保存并暂停当前计时；重新打开后保持静音，需要手动继续。
- 运行时每 30 秒自动保存一次，正常退出和重要操作会立即保存。
- 提前结束会记录已投入的时间，但不增加成长；完成休息也不增加成长。
- 日记保留最近 1000 条，界面显示最近 30 条；总时长和成长一直保留。

存档文件是 `aquarium.json`，桌面版放在系统的应用数据目录（macOS 上是 `~/Library/Application Support/小海底`）。浏览器模式使用单独的 `mygo-aquarium-browser` 配置目录。`-data-dir` 参数可以指定其他目录，方便隔离测试；同一个存档目录只应由一个实例写入。

设置里的「备份与恢复」可以一键导出整个存档（带版本号的 JSON 文件），换机或重装前先备一份；导入前会校验文件格式，失败时当前存档不会有任何改动。导出再导入，内容完全一致（同版本内往返无损）。旧版直接拷贝的 `aquarium.json` 也可以直接导入。

## 从源码构建

需要 Go 1.27.1 或更高版本。在项目根目录执行：

```sh
# 运行桌面版
CGO_ENABLED=0 go run .

# 在浏览器中运行（只监听本机回环地址）
CGO_ENABLED=0 go run . -web 127.0.0.1:4173

# 构建 macOS 应用和 dmg，输出到 build/darwin-arm64
CGO_ENABLED=0 go tool mygo build -sign=- -skip-notarize .

# 运行测试
CGO_ENABLED=0 go test ./...
node --test --test-concurrency=1 tests/*.test.mjs
```

自动更新由 `mygo.json` 的 `updates` 配置（公钥和发布仓库）。签名更新包的私钥不在仓库和配置里，正式发布时通过环境变量传入：`MYGO_UPDATER_PRIVATE_KEY="$(cat <私钥文件>)" CGO_ENABLED=0 go tool mygo build .`。没有私钥时照常构建，只是不生成更新包，已安装的小海底就收不到这一版。

构建其他平台时加上 `-platform`，例如 `-platform windows/amd64,linux/amd64`。Windows 和 Linux 版还没有经过实际测试。

桌面版使用系统自带的 WebView：

- **macOS：** WKWebView。
- **Windows：** WebView2。
- **Linux：** GTK 3 和 WebKitGTK 4.1（或 4.0）。播放背景音还需要 GStreamer 的 MP3 解码插件（gst-plugins-good 1.18 或更高版本）。菜单栏图标依赖 Ayatana AppIndicator，缺少时会退回普通窗口，“收起”变成最小化。Wayland 下窗口位置由合成器决定。

### 更换背景音

录音由 `build-sounds.sh` 生成并放在 `web/sounds`，平时构建不需要运行它。要换录音，修改脚本开头的表格，再运行 `./build-sounds.sh`。运行需要 curl、ffmpeg 5 或更高版本（含 libmp3lame）和网络。

脚本会截取片段、调整响度、编码成 MP3，所有录音合计不超过 30 MB。时钟、木鱼和卡农的循环位置写在 `web/audio.js` 里，换这三种的录音时要一并修改。

### 图标

计时圆环里的小鱼图标在 `icon.go` 里绘制。修改后运行 `go run . -export-icons`，重新生成 `assets/icon.png`、`web/favicon.png` 和 `web/mark.png`。

### 测试

测试覆盖：
- **计时：** 暂停和恢复后的实际时长、提前结束、完成只结算一次、休眠时暂停、休息不增加成长。
- **存档：** 访客存档、恢复设置、保存失败时回滚。
- **访客：** 第一轮遇见小丑鱼，先遇见没见过的物种，旧存档也能遇见新物种，页面认得每一个物种。
- **录音：** 每种录音都已打包，且合计不超过 30 MB。
- **动态效果：** 原生与浏览器减少动态效果偏好、喂鱼后的静态状态，以及窗口隐藏后动画的暂停和恢复。
