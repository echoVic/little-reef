# v0.4 Release notes 定稿

> 来源：飞书物料定稿 docx/OQ8Qd9SaHokTnUxW7zCcSSIbncf（revision 5，2026-10-24）。
> **用途**：CHANGELOG.md 新增节 + GitHub Release 正文。
> **风格基准**：对照 CHANGELOG 0.3.0/0.2.x——中文、条目式、动词开头、无 emoji、只写用户可感知的行为。

## CHANGELOG.md 条目（写入 CHANGELOG.md）

```markdown
## 0.4.0

- 新增「这段时间」回顾面板：本周、本月和累计的专注时长与轮数，还有一起度过的天数、图鉴完成度和当前成长阶段，展开就能看
- 统计只作正向记录：不显示连续打卡，没有目标，也不提醒
- 设置里新增「备份与恢复」：存档可以一键导出，换机或重装前先备一份；导入前会校验，失败不会影响当前存档
- 存档导出再导入，内容和原来完全一样，图鉴与总时长完整保留
- 挂件模式保持不变，统计只在主窗口展开查看
```

## GitHub Release 正文（Release body，可带链接与物料）

```markdown
这一版给「看得见的进步」和「数据安全」各加了一层：

- 「这段时间」回顾面板：本周、本月和累计的专注时长与轮数、一起度过的天数、图鉴完成度、当前成长阶段——展开就能看。它只做正向记录：不显示连续打卡，没有目标，也不提醒。
- 「备份与恢复」：设置里一键导出存档，换机或重装前先备一份；导入前会校验，失败不会影响当前存档，成功导入后一切如初。

官网新增中英对照与回顾面板介绍：https://reef.echovic.com

---

**下载**：little-reef-0.4.0-macos-arm64.dmg（需要 macOS 12 或更高版本，Apple 芯片）

已安装的用户会自动收到更新提示；也可以在菜单栏图标右键选「检查更新」。
```

**两条备注**：

1. 「内容和原来完全一样」一句以 Task 3 往返无损验收实际通过为前提——未通过则删改此条（计划 9.3 原则不变）。
2. 版本号与 DMG 文件名按实际构建产物替换；Release 正文中的更新提示机制描述以 CHANGELOG 0.2.2/0.2.3 既有行为为准。
