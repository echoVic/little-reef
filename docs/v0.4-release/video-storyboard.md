## 初剪版与真机重录说明（W3 实施注记）

初剪采用「分镜画面卡（真实 UI 截图）+ 字幕」合成，镜头节奏按上表时间分配。需真机重录的镜头：

- **S1 / S6**：需要真实桌面壁纸与挂件小窗位置，headless 无法拍。
- **S2 / S3**：空格开始、计时滚动、水草成长动画、菜单栏小鱼游动——需要真实桌面交互录屏（可倍速后期压短）。
- **S5**：音量滑杆的连续动画与声音切换手感，截图序列只能示意。

可由初剪直接使用的镜头：**S4**（「这段时间」面板展开态，headless 截图已覆盖真实 UI）。

### 真机录制指引（QuickTime）

1. 准备预置存档：图鉴 5/15、称号「萌芽」段、本周有记录（可用浏览器模式跑几轮后导出，再替换桌面存档）。
2. QuickTime Player → 文件 → 新建屏幕录制 → 选「录制大小」为 Retina 全画布。
3. S2：空格开始 → 让计时滚动几秒（可倍速）→ 停在主窗口画面。
4. S3：完成一轮后拍水草长高瞬间 + 图鉴页停留 0.5s。
5. S5：声音面板海浪→咖啡馆切换，手推音量滑杆。
6. S6：按 ⌘⇧A 收为挂件，定格在 logo + 地址帧 2s。
7. 后期按上表时间轴剪接，叠加 6 条字幕卡。
