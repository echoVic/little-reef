01中国风

宣纸上的水族箱。墨分五色、留白即水，唯一的暖色（朱砂）只在点睛处出现；三套变体由「疏朗」到「叠染」递进，生物数量与动效密度均低于默认写实主题。

三套主题文字对比度均为 WCAG 脚本实测：正文主色 9.49~11.15:1（AAA），次色 4.66~4.84:1（AA）。控件几何家族级恒定：菜单栏 16×16pt、按钮高 28pt、进度环宽 4pt、卡片圆角 10pt、开关 36×22pt；完成反馈分别为朱砂印章落下 / 青花波纹一圈 / 金线一亮，均一次性、≤600ms。

范围说明：本文档包含 3 套中国风主题变体（水墨兰亭 / 青花瓷韵 / 青绿江山）。卡通漫画风、可爱风由其他设计师并行负责。

全局约定（三个主题共用，不重复）：控件几何尺寸为家族级常量而非主题 token——菜单栏图标 16×16pt（@2x 提供 32×32）、按钮高 28pt、进度环宽 4pt、卡片圆角 10pt、开关 36×22pt。所有主题文字对比度数值均为 WCAG 相对亮度公式脚本实测值，非目测估计。

主题一：水墨兰亭（cn-shuimo）

1. 主题名称与代号

水墨兰亭 · 代号 cn-shuimo

2. 气质定位

「把水族箱养在一张宣纸上」——一套文人画式的水下世界。墨分五色，留白即水：鱼是纸上一点浓墨，珊瑚是枯笔枝干，气泡是虚圈。整套界面只有一个暖色（朱砂），用于极少数需要点睛的地方，其余全靠墨阶深浅说话。安静、疏朗、不争。

3. 适用场景

长时间深度专注（写作、阅读、连续编码）的首选主题；夜间想收敛心神、不愿被色彩打扰的时刻。适合偏爱极简与大量留白的用户——它是最接近「一张安静的纸」的主题。

4. 色彩体系

色相逻辑：全画面无彩色墨阶（约 40°~50° 的暖灰基调）+ 唯一暖色朱砂做强调，即传统设色的「万墨丛中一点朱」。文字对比度（实测）：textPrimary 对 bgBase 11.15:1（AAA），textSecondary 对 bgBase 4.66:1（AA），accent 对 controlBg 4.62:1（AA）。

5. 水族箱背景画面

  • 构图（远中近三层）：上 1/3 为大面留白「水天」，仅在顶缘有一道月白天光亮带；中景偏左放一株大型枯笔鹿角珊瑚，偏右 2~3 笔兰叶水草（疏密呼应，忌对称）；底部 1/5 为沙洲浅赭，用横向枯笔皴擦出 3~4 道深浅笔触。
  • 光照：顶部柔和漫射天光，色温 4500K 偏暖；不出现体积光柱与光斑——留白主题里光斑即噪音。
  • 水体通透度：极高。留白本身就是通透，唯一的深浅变化是从 bgGradient 到 bgBase 的自下而上渐隐。
  • 静态元素：宣纸底纹（512×512 可平铺 tile，纹理对比度极低）、沙洲、珊瑚。
  • 动态元素：2~3 尾墨鱼、苔墨水草 ±3° 缓摆、每屏不超过 3 个空心墨圈气泡。

6. 鱼类与生物视觉

造型语言：轮廓由「笔触」构成——起笔重、行笔轻、收笔飞白（透明度渐隐），全部生物带 1px 淡墨轮廓，不用任何高光材质。

  • 墨鳞鲤（代表鱼 1）：纺锤形，体长约为画面宽 1/10；背部浓墨 #2B2722 一笔铺出，向腹部过渡为 60% 透明淡墨，尾鳍两笔撇出、末端飞白（opacity 0.4）；单尾或两尾同游，巡游速度为默认主题的 0.3×，路径为长弧线、几乎不转向。
  • 齐白石式墨虾（代表鱼 2）：躯干 6 节、节节淡墨（#6E6A5C @70% 透明度），双长须为 0.5px 细线向前伸出体长 1.5 倍；行为以「停」为主——挂在珊瑚枝上静置，每 20~40 秒一次后退弹跳。
  • 淡墨蟹（代表鱼 3）：壳用浓墨点染、螯足用淡墨，趴在沙洲上以 0.1× 速度横向缓爬，是画面中「最慢的元素」。
  • 珊瑚/水草：珊瑚为枯笔鹿角状，主干 2.5px、末梢 1px，枝头留白断笔；水草用兰叶描「一笔一叶」，叶尖飞白。
  • 群游建议：不群游。文人画里鱼永远只有两三尾，本主题生物数量硬上限 3，遵循「疏可走马」。

7. 界面控件样式

  • 菜单栏图标：template 单色剪影，16×16pt，一条 S 形单笔鱼轮廓（一笔画出，不断线）；专注中 3 帧横摆动画（位移 ±2px，1.2s/循环），暂停/休息时停帧——与现有默认主题行为一致。
  • 计时器卡片：宣白 #FAF7EF @90% 不透明，圆角 10pt，描边 1px #C6BFAE，阴影 0 2px 8px rgba(51,48,43,0.12)；卡片内部计时数字用浓墨，左上角状态点 6pt（进行中松烟绿/休息赭墨）。
  • 按钮：高 28pt，圆角 8pt，描边 1px #C6BFAE，默认底 controlBg，hover 底换 bgBase，按下不透明度降至 80%。
  • 进度环：环宽 4pt，底环 #C6BFAE，走针 #4E6E5D；完成时不弹动画彩带，只做一件事——一枚 16×16pt 朱砂印章（印文可用「休」字）在环心 400ms 内淡入并轻轻落下（位移 2px），随后常驻本次记录条目。
  • 开关：36×22pt 胶囊，圆角 11pt，关闭态描边 #C6BFAE + 底 controlBg，开启态填充 #4E6E5D。
  • 卡片（统计/列表）：圆角 12pt，其余同计时器卡片；卡片标题左侧加一枚 8pt 淡墨方印作装饰锚点。

8. 字体建议

  • 标题："Kaiti SC", "LXGW WenKai", "Songti SC", serif（楷体的手写感呼应笔墨；未装 LXGW WenKai 时优雅回退，不依赖安装）
  • 正文："PingFang SC", "Hiragino Sans GB", sans-serif
  • 计时数字："SF Mono", "Menlo", monospace（等宽数字避免跳动；此主题刻意不用书法体做数字，保证专注中读数零负担）

9. 动效与声音

  • 缓动：cubic-bezier(0.33, 0, 0.2, 1)——偏慢的缓入缓出，模拟墨迹在水中沉降。
  • bubbleDensity：0.2×（每屏 ≤3 个，空心墨圈）；driftSpeed：0.3×；水草摆幅 ±3°、周期 6s。
  • 环境音（可选、默认关）：极低音量古琴泛音 + 一滴砚台水声，无旋律循环，音量上限内置为系统 20%。
  • 减少动态效果兼容：开启后鱼全部停靠为中景悬停姿势、水草垂直、气泡消失、印章淡入改为无位移直接显隐；计时数字变化保留 150ms 纯淡入（不属动态效果，属状态提示）。

10. 落地备注

  • Token 映射：bgBase/bgGradient/waterLight/sand（背景层 4 token 原值直填）；coral/fish/seaweed/bubble（生物层 4 token）；accent/timerActive/timerPause/controlBg/controlBorder/textPrimary/textSecondary/menuIcon（UI 层 8 token 全部使用）；bubbleDensity=0.2、driftSpeed=0.3、easing=墨沉曲线、ambientAudio=guqin-drip。
  • 资产清单：鱼 sprite 3 套（墨鳞鲤/墨虾/墨蟹，各含游动帧 3 帧 + 悬停帧 1 帧）；珊瑚贴图 2 套（枯笔鹿角大/小，各含成长 3 阶段）；水草贴图 1 套（兰叶描，3 帧摆动）；菜单栏图标 1 枚（template PDF）；朱砂印章 PNG 1 枚；宣纸纹理 tile 1 张（512×512）。
  • 特殊实现：留白区域就是背景层本身，禁止叠加任何渐变光斑/体积光粒子；所有透明度通过 CSS 变量挂 token，不硬编码；飞白效果用 sprite 内置 alpha 通道实现，不做运行时滤镜（省性能）。

主题二：青花瓷韵（cn-qinghua）

1. 主题名称与代号

青花瓷韵 · 代号 cn-qinghua

2. 气质定位

「把海底烧进一只梅瓶里」——钴蓝在瓷白釉面上晕散，鱼是缠枝纹间游动的一笔青花。整套画面只有两种颜色：瓷的白与钴的蓝，最多再借一点瓷器底足的露胎赭。清凉、规整、雅而不冷。

3. 适用场景

白天与上午的工作专注段——它是最清爽明亮的一套，与 macOS 浅色外观共处最和谐；适合喜欢蓝白配色、想要「清爽但不性冷淡」氛围的用户。

4. 色彩体系

色相逻辑：单色相策略——全部层级色围绕青蓝 210°±10° 做明度分层，唯一的暖色是露胎赭（瓷器未施釉的底足色），仅用于沙地与暂停态，形成「冷主暖辅」。文字对比度（实测）：textPrimary 对 bgBase 10.70:1（AAA），textSecondary 对 bgBase 4.75:1（AA），accent 对 controlBg 6.62:1（AAA）。

5. 水族箱背景画面

  • 构图：上 2/5 为釉白向天青沉的极缓垂直渐变（模拟釉层厚度的感觉，渐变跨度大、对比弱）；水面下 1/6 处一条 45° 入射的月白高光带（柔和椭圆羽化，非镜面反光）；中景左右各一组缠枝珊瑚（左高右低，呼应不等边构图）；底部 1/6 露胎赭沙地，边缘做一圈 2px 的「釉面垂流」过渡（青釉色滴垂入沙地的界线）。
  • 光照：45° 斜向天光，色温 5600K 中性偏冷，仅一条高光带，无光柱。
  • 水体通透度：高——白瓷底色本身即通透感来源。
  • 静态元素：全幅叠加极细开片纹路 tile（512×512，线宽 0.5px，透明度 4%，近看有瓷面细节、远看不可见）、沙地、珊瑚。
  • 动态元素：青花鱼群、水草缓摆、中等密度的白釉泡。

6. 鱼类与生物视觉

造型语言：鱼体以瓷白为底、钴蓝纹样绘身，轮廓圆润无棱角（瓷器没有尖锐转折）；纹样借鉴青花分水技法——同一笔内有浓淡晕散。

三种不同的「印刷与手绘」语言：波普的硬色阶与网点、赛璐璐的双色阶平涂、墨线的线稿淡彩。统一规则：降饱和撞色、深色轮廓收边、动效时长下限 0.25s、禁止高频循环。

主题一：波普（cm-pop）

1. 主题名称与代号

波普，代号 cm-pop。

2. 气质定位

一句话定位：一张贴在桌面上的波普漫画页，海底是印刷色的，但情绪是松弛的。画面像 Lichtenstein 式漫画定格：色块硬切、网点规则、轮廓粗而稳，鱼是漫画里的配角而非真实物种。撞色全部降饱和处理，杜绝红黑高对比的攻击性；「喧闹」的部分只保留在造型趣味上，色彩始终保持明快而非激烈。

3. 适用场景

  • 想要视觉上「换个心情」的用户：下午犯困、周末休整，需要一点明快但不需要刺激
  • 喜欢复古漫画、美式插画审美的用户；桌面本身偏简约（深色壁纸或纯色壁纸）时对比效果最佳
  • 白天的专注时段：亮色印刷底比写实深海底在强光环境下更易读

4. 色彩体系

色相逻辑：冷调青绿占约 70% 画面面积，暖调橘粉占 25%，柠檬黄点缀 5%；所有撞色被统一的深海军蓝轮廓「收边」，使对比热闹但不刺眼。全部为纯平涂色，无渐变（波普语言的硬色阶分界代替渐变）。

主题二：赛璐璐（cm-cel）

1. 主题名称与代号

赛璐璐，代号 cm-cel。

2. 气质定位

一句话定位：90 年代手绘动画里那一格清澈的浅海，吉卜力式的平涂和光柱。颜色是分层的、干净的，每种颜色只有「亮面/阴影一阶」两个色阶，像逐帧画在赛璐璐片上。明亮但不饱和过度，光柱柔和、水草缓缓摇——三套中最接近现有写实主题的「安静陪伴」气质，是卡通风里的默认安全款。

3. 适用场景

  • 首选入门卡通主题：想要轻松一点、又不希望风格突变太大的用户
  • 清晨/上午的高质量专注时段，喜欢日系动画审美的用户
  • 桌面偏浅色壁纸、或需要长时间挂在水族箱前发呆放松的用户（明度分布均匀，长时间注视不疲劳）

4. 色彩体系

色相逻辑：全画面一个统一色温的「清透水色」底（青绿系），生物与 UI 用同明度区间的暖橘、樱粉、草绿点缀；阴影不用黑灰色，而用各色的同色相加深一阶（赛璐璐二分法），保证画面整体始终明亮。每个颜色只存在「固有色 + 一阶阴影」两层，无第三层。

5. 水族箱背景画面

以 1600×900 逻辑分辨率描述：

  • 远景（上 0–30%）：亮青 #6FD0CE 亮带，底部以一条缓弧曲线硬切到 #BDEDE9（赛璐璐色阶，无渐变过渡）。三束白色光柱从水面斜贯至画面中部（倾角 15°，宽 40 / 30 / 24 px、间距约 200 px，边缘平直无羽化，不透明度 80%），以 8 s 周期做 72%–88% 的透明度呼吸——极缓，几乎察觉不到。
  • 中景（30–70%）：左、右各一丛鳗草（5–7 片，叶形为两段贝塞尔的飘带形，高 100–160 px，#67C58F，每片叶根部向下 1/3 处铺一片 #52AB79 月牙形阴影阶）；中部偏左一群樱粉海葵（6 根圆头触手，触手末端圆球 #FF9AA8、柄 #E57F92 阴影阶）。
  • 近景（70–100%）：两道奶油沙丘（#F2E8CF，背光侧 #E3D5B5 阴影阶硬边色块）；左下一枝鹿角珊瑚（樱粉 #FF9AA8，枝端圆钝）；右下一块圆角礁石（固有色用沙丘阴影色 #E3D5B5，阴影阶再加深为 #CDBB98——遵循同色相加深规则）。
  • 全元素通用：描边 #17414D、2 px（细描边，赛璐璐片的干净线条）、round join；所有阴影为硬边形状（沿轮廓偏移 2–4 px 的月牙色块），禁止羽化和半透明叠加。
  • 动态元素：海草摇摆、光柱呼吸、鱼群游动、气泡；「减少动态效果」时全部取中位静帧。

6. 鱼类与生物视觉

通用造型语言：圆钝可爱的动画造型，2 px 深青墨描边，平涂固有色 + 单块硬边阴影阶，白色高光只点眼睛。

  3. 蝴蝶鱼「阿黄」：扁圆身柠檬黄 #FFC94D（此主题内黄色仅此一种用法），眼带一条垂直深青条纹，吻部尖。贴礁石附近慢游，转弯半径大、动作绵软。

墨线，代号 cm-ink。

2. 气质定位

一句话定位：一本摊开的速写本，海底是几笔炭墨勾出来、再淡淡晕了一点水彩。大面积留白，水用弧线表示而非色块，鱼像日记本里的小插图。三套中最安静、纸感最强的一套，色彩从不铺满，永远只是墨线的淡彩注脚。它把「无压力」推到极致：连颜色都不着急。

3. 适用场景

  • 深度专注、夜间或需要最低视觉干扰的时段；对明快色也嫌吵的用户
  • 喜欢手账、速写、独立漫画审美（如《海兽之子》线稿、《一人之下》水墨插页气质）的用户
  • 桌面本身色彩丰富（照片壁纸）时，墨线主题的留白与任何壁纸都不打架

4. 色彩体系

色相逻辑：纸底一色（米白）撑起 60% 以上画面；墨线为唯一「结构色」；淡彩仅四五种（青、蓝、粉、绿、黄），全部以 40–70% 不透明度薄涂在对应造型上，像水彩在宣纸上留下的那层色。没有任何深色大面积底，天然低刺激。

5. 水族箱背景画面

以 1600×900 逻辑分辨率描述：

  • 远景（上 0–35%）：纸底留白为主；水面用 3 条起伏弧线表示（2 px 炭墨，线条每隔约 40 px 带 ±0.5 px 的预置抖动偏移——手绘微颤感烘焙进矢量路径，非实时随机）；弧线之下一片 #CDE6E4 淡彩薄刷（45% 不透明，上边缘贴弧线、下边缘羽化 8 px 消散于纸底）。右上角 2 颗纯圈线气泡（无填充）。
  • 中景（35–70%）：左侧一丛水草（4 条 S 形曲线勾勒，苔绿 40% 淡彩只填叶身下半段，叶尖留白）；右侧一株枝珊瑚（炭墨枝干 + 胭脂粉 60% 淡彩点在枝端圆头）；中部点缀 2 朵五线海星（赭橘 50%，仅 5 条短弧线 + 中心点）。
  • 近景（70–100%）：底部一道大弧沙丘（稻草黄 45% 淡彩），背光处 45° 排线（1.2 px、间距 5 px、每段 12–18 px 长、炭墨 60% 不透明）；左下角一只简笔小蟹（两笔弧线壳 + 两条钳弧，赭橘 50% 淡彩壳面）。

  • 动态元素：极少量——鱼、圈线气泡、水草微摆（见下）；沙丘、排线、珊瑚完全静态。

6. 鱼类与生物视觉

通用造型语言：一笔到位的简笔弧线轮廓，淡彩只填身体中部、边缘留白，眼睛大而呆。

  1. 霭蓝小鱼（主角）：椭圆身两笔弧线勾出，鱼腹一条内弧线留白；雾霭蓝 70% 淡彩填背部 2/3；眼睛为 5 px 炭墨实心圆 + 上方一条 3 px 弧线眼睑（呆萌感来自这条眼睑）；尾鳍一片三角、无彩。游动：横穿全屏约 40 s（三套中最慢），几乎贴沙丘弧线平游，正弦起伏 ±5 px、周期 8 s，尾鳍不做帧动画、仅随路径自然摆。
  2. 纸鹤河鲀：纯线稿无淡彩——正圆身炭墨描线，身上 6 条短弧线小刺；每 6 s 一次极缓慢的「呼吸鼓身」（scale 1.00→1.02→1.00，3 s 完成一半周期），像纸上画在轻轻浮动。
  3. 赭橘小虾：3 节弧线身体 + 两根 1 px 长须（各约 30 px，尾端 2 px 微弯），淡彩 50%；以每 8 s 约 20 px 的速度倒退式缓移——慢到需要盯一会才发现它在动，这是本主题的趣味彩蛋。

群游建议：本主题不设群游。鱼以「独居插画」方式出现，同屏 ≤2 尾且永不同框相遇——速写本上每页只画一只小动物，翻页才见下一只（可作为「每次专注完成后随机换一只」的实现伏笔）。

03可爱风

甜得克制、软得安静。可爱来自圆润造型、腮红与低饱和配色，不来自动效与音量；饱和度整体压在 30% 以下，强调色只允许出现在进度环与选中态。

三套主题对比度脚本实测：正文主色 9.8~10.2:1，次色 4.5~5.1:1，大号状态色 3.5~4.3:1。菜单栏图标一律 template image（黑白 alpha）由系统适配；控件基线：按钮 32px、圆角 10px、卡片 16px、开关 28×16px、计时数字 64px——切主题只换 token，不换布局。可爱风暂未生成 mood 图。

设计前提：三套变体均延续「安静陪伴」气质——可爱来自圆润造型与低饱和配色，不来自动效密度与音量；控件保持克制，无打卡、无提醒、无催促性动效；全部动效层在系统「减少动态效果」开启时退化为静态整帧插画。

变体一 · 马卡龙（ct-cream）

1. 主题名称与代号

马卡龙 · 代号 ct-cream

2. 气质定位

一句话定位：一盘低饱和的马卡龙沉进奶油色海底。氛围：像午后烘焙坊橱窗，甜得克制、软得安静；所有颜色都像掺了牛奶，饱和度整体压在 30% 以下。画面给人的感受是「暖」而非「甜腻」——看久了不腻，是能待一整个下午的颜色。

3. 适用场景

  • 长时间深度工作（写代码、写长文）时选用：低对比、无高饱和刺激，视觉负担最小；
  • 傍晚与夜间工作时段：暖色底对屏幕蓝光环境更柔和；
  • 喜欢被温暖感包围、但不想被粉色包围的用户的第一只可爱主题。

代表生物（3 套 sprite）： 1. 果冻水母（主角，非鱼但作为主题签名）：葡萄果冻 #C3A6E0 85% 半透明伞体（半圆、直径 56px、底边圆角 8px），下摆 4~6 条圆头短触须（描边 4px、长 20~30px）；垂直漂浮 ±8px、周期 4s，水平漂移 3px/s，伞体每 4s 完成 3% 的收缩-舒张（推进感，极缓）。 2. 苏打小鱼：水彩蓝 #8FC3E8 80% 纺锤偏椭圆身体（约 40px），背部一道白色高光弧（描边 3px），尾鳍半圆。群游：4~6 条，纵向松散排布在光带下方（像被光照托着），间距 2× 体长，速度 8px/s，相位差 0.4s。 3. 玻璃虾：近乎透明——#FFFFFF 40% 填充 + 冰蓝灰 #8FB8C9 描边 2px 的弯月形虾（约 40px），贴沙地爬行 3px/s，是「找到它」的安静彩蛋。

游动节奏总则：全主题最慢——水母主题本身就是「漂浮」而非「游」，与无压力原则天然契合。

7. 界面控件样式

  • 菜单栏图标：template image = 果冻水母剪影（半圆伞 + 3 短须）；窗口内图标着色 #3F6E85；专注时触须轻摆 ±3°、周期 3s（比 ct-cream 更慢），暂停与减动效下静止。
  • 计时数字：64px，进行中海盐墨蓝 #3F7A93、暂停荔枝粉 #D99AA6 + 90% 不透明度。
  • 按钮/卡片：同基线尺寸（按钮 32px 高、圆角 10px；卡片圆角 16px、内边距 20px）；材质上果冻主题专属建议——controlBg 云雾白 #FDFFFF 叠加 8% 半透明（rgba(253,255,255,0.92)），让背景的水色微微透上来，描边冰蓝灰 #CFE0E8，阴影 0 2px 8px rgba(47,59,74,0.06)（三套中最轻）。
  • 进度环：6px、圆头、苏打蓝 #4E96B4，轨道 #CFE0E8；可在环内侧加 10% 白色内高光呼应果冻质感。
  • 开关：28×16px，开启态 #4E96B4，0.25s ease-in-out。

8. 字体建议

  • 标题："LXGW WenKai", "PingFang SC", sans-serif（若希望冷感更利落，可改 "ZCOOL KuaiLe", "PingFang SC", sans-serif，站酷快乐体免费可商用，更圆润跳脱——二选一，默认前者更克制）

  • 计时数字："SF Pro Rounded", "SF Pro Display", "PingFang SC", sans-serif（weight 510，tabular-figures；果冻主题下不加粗一级，保持清透）

9. 动效与声音

  • 缓动：cubic-bezier(0.42, 0, 0.58, 1)；水母漂浮为正弦叠加，无回弹。
  • 气泡：8~12 枚（三套中最高，因气泡本身透明、视觉密度低），直径 2~6px，上升 7px/s。
  • 漂移 driftSpeed：果冻草 5s、光带 10s、水母收缩 4s——整体节奏比前两套再慢半拍。
  • 环境音 ambientAudio：默认关闭；可选「水下气泡环境音」极低音量（-30 LUFS 级）。
  • 减动效对齐：光带呼吸、珊瑚微颤、水母收缩、鱼、气泡全部停止；渲染静态整帧（水母定格在收缩中位）；菜单栏图标静止。功能不受影响。

Token 骨架最终版（在共享骨架上做 4 处修订，其余原样保留）：

  1. 新增 meta 层：themeId / displayName / styleFamily / version / minAppVersion / supportsDarkAppearance / reduceMotionFallback——主题的自描述信息不散落在代码里。
  2. 生物层 token 支持成长阶段：coral / seaweed 增加可选 stages 数组字段（如 "coral": ["#幼","#中","#成"] 或贴图 grow-1..3），与珊瑚成长玩法对齐；写实主题同样补齐此字段。
  3. 动效层增加两个守门 token：bubbleDensity 与 driftSpeed 增加全局上限校验 ≤1.0×默认值（默认值即写实主题的 1.0×；卡通/可爱风交付的「同屏 N 颗」等绝对值按 1080p 窗口折算），ambientAudio.defaultOn 强制为 false——把「无压力」原则变成 schema 级约束，任何主题包超限直接校验失败。
  4. UI 几何按家族常量管理：圆角/尺寸/环宽不进 token（见 d 节），token 只管颜色、材质、密度与缓动。

兼容现有写实默认主题：写实主题作为 themeId: "reef-realistic"、styleFamily: "realistic" 纳入同一目录与同一 token 契约——把现在硬编码在 web 前端里的颜色/速度值抽取成它的 theme.json（此为重构动作，不改任何视觉表现）；其余主题未提供的 token 允许回退继承 reef-realistic 的值（继承机制），这样新主题可以只写差异项，不必每次填满全部 token。代号命名空间约定：中国风 cn-*、卡通漫画风 cm-*、可爱风 ct-*、写实 reef-*（默认），均为小写连字符。

b) 切换入口建议

候选入口 结论 理由
菜单栏下拉子菜单（推荐主入口） ✅ 采用 菜单栏图标是唯一常驻入口，点开即可切、切完即走，全程不弹窗口、不夺焦点，最符合「不打断专注」；实现成本最低
设置面板主题页（推荐辅入口） ✅ 采用 承载完整列表：主题名 + 缩略预览 + 一句气质描述；首次探索用户从这里选
右键水族箱快捷菜单 ❌ 不推荐 水族箱窗口常在后台，右键路径不稳定；且容易在「看鱼」时误触弹菜单，惊扰感与产品气质相悖
悬浮快速切换球 ❌ 不推荐 额外常驻 UI = 违反无压力原则

推荐方案：菜单栏下拉菜单加「主题 ▸」二级单选列表（带勾选态），设置面板提供带预览的完整版；两处入口共享同一状态，切换即时生效、无确认弹窗、无模态。

c) 切换的工程注意事项

  1. 主题是纯表现层，永不碰数据：珊瑚成长、到访生物、专注记录全部存于 aquarium.json，与主题无关。切换 = 重绑 CSS 变量 + 替换 sprite 引用，严禁触发任何存档读写——这是本功能最重要的一条红线，回归测试必含「切换 100 次后 aquarium.json 字节级不变」。
  2. 资产加载与缓存：主题包惰性加载，首次切换时旧主题继续显示、新包在后台预载（鱼 sprite 建议合入纹理集减少 IO）；已加载包 LRU 缓存上限 3 个，防止常驻内存随主题数膨胀；webview 静态资源沿用现有缓存机制，theme.json 带版本号做缓存键。
  3. 深色模式/系统外观兼容：本批九套主题均为浅色（纸绢/奶昔/印刷底）主题，主题自带外观基准、不随系统深色翻转（meta 中 supportsDarkAppearance: false 显式声明）；菜单栏图标走 template image 由系统自动适配深浅菜单栏——这也是各主题 menuIcon 都定义为 template 的原因。深色变体留给后续迭代，不做运行时自动反转（纸绢色反转会出现「夜观书画」的怪异负片）。
  4. 切换过渡动效：600ms 交叉淡入——新主题背景层先入，生物层 sprite 逐个换装（避免「集体闪现」）；开启「减少动态效果」时直接硬切、无过渡。切换本身不附带任何庆祝性动效（无水花、无波纹）。
  5. 命名与目录：见 a 节结构；themeId 全小写连字符、与目录名严格一致；version 用 semver，破坏 token 契约升 major、加资产升 minor、改色值升 patch；theme.json schema 建议用 Go 侧 struct 定义并生成 TypeScript 类型给 bindings.ts，保证两端一致。

d) 主题间一致性规则

  1. 布局与行为不变：计时逻辑、菜单结构、卡片信息层级、「无压力」文案（不打卡、不催促）对所有主题完全一致；主题只替换 token + 资产 + 文字字体栈 三样东西。
  2. 几何基线按风格家族定义，家族内恒定：控件几何是家族级常量、不进主题包、同一家族内切主题不得改变——本方案三大家族各自交付的基线为：中国风（菜单栏 16×16pt、按钮高 28pt、进度环宽 4pt、卡片圆角 10pt、开关 36×22pt）、卡通漫画风（菜单栏 22pt、按钮高 34~36pt、卡片圆角 14~20pt、开关 44×26pt、进度环 3~12pt）、可爱风（按钮高 32px、卡片圆角 16px、开关 28×16px、计时数字 64px、进度环 6px）。跨家族允许几何不同（它是家族气质的一部分），但各家族内部必须保持常量。
  3. 状态色语义全局统一：timerActive 恒为「进行中」、timerPause 恒为「暂停/休息」，色相可换、语义不可换；完成反馈统一为「一次性、非循环、≤600ms」的轻动效（印章/波纹/金线/河豚鼓起/墨线收锋等形式不同、重量相同）。
  4. 入版统一检查清单：每个主题合入前过同一套门禁——文字对比度（正文 ≥4.5:1、大字与图形 ≥3:1，用脚本实测）、「减少动态效果」静态方案完整、bubbleDensity/driftSpeed ≤1×、环境音默认关、菜单栏图标为 template、theme.json schema 校验通过。本文档九套主题的对比度实测值已随附，可直接作为验收基准。
